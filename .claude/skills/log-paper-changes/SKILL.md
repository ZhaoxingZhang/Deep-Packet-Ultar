## Task

将论文/代码改动以简洁格式记录到研究日志（`.agent/研究日志.md`），只记录改什么和怎么改，不记录实施方式。

## Steps

1. **读取研究日志末尾**：使用Read工具读取`.agent/研究日志.md`最后30-50行，确认现有格式
2. **格式化改动内容**：将输入的改动列表按标准格式整理
3. **追加到日志**：使用Write工具（追加模式）将格式化后的内容追加到研究日志末尾

## Output Format

```markdown
## 日期：{date}

### {主题}

{改动列表，每个改动格式：}
**{序号}. {改动标题}** ({位置})
- {改动前描述}
- {改动后描述}
```

## Format Requirements

1. **简洁为主**：每个改动点1-2行，不超过3行
2. **只记改什么**：记录改动内容，不记录实施方式
3. **不包含**：
   - Git commits、命令行操作
   - 文件路径、目录结构
   - 实施步骤、调试过程
   - 实验结果、性能数据
4. **技术细节优先**：明确位置（行号、章节、函数名）
5. **对比清晰**：改动前后用箭头、引号或破折号标注

## Input Parameters

通过conversation传入，格式如下：

```python
changes = [
    {
        "location": "Line 31",
        "title": "添加技术背景",
        "before": "提到加密技术但没解释原理",
        "after": "添加加密原理：明文→密文，载荷不可见，DPI失效"
    },
    # ... 更多改动
]

date = "2026年3月7日"  # 可选，默认使用当前日期
theme = "论文第一章系统性改进"  # 必需，工作主题
```

## Example

**Input**:
```python
changes = [
    {"location": "Line 31", "title": "添加技术背景", "before": "提到加密技术但没解释原理", "after": "添加加密原理：明文→密文，载荷不可见，DPI失效"},
    {"location": "Line 43", "title": "修正创新归属", "before": "提出了加权CE损失", "after": "修正为：创新性地应用加权CE到门控网络"}
]
date = "2026年3月7日"
theme = "论文第一章系统性改进"
```

**Output**:
```markdown
## 日期：2026年3月7日

### 论文第一章系统性改进

**1. 添加技术背景** (Line 31)
- 提到加密技术但没解释原理
- 添加加密原理：明文→密文，载荷不可见，DPI失效

**2. 修正创新归属** (Line 43)
- 提出了加权CE损失
- 修正为：创新性地应用加权CE到门控网络
```
