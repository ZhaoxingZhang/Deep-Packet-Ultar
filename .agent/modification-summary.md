### **任务2：修正门控融合机制** ⚠️ 高优先级

#### 2.1 修正门控公式
**修改位置**：3.5.3节（第466行）

**原文（有问题）**：
```latex
y_GEE(x) = α(x) · y_baseline(x) + (1-α(x)) · y_expert(x)
其中 α(x) ∈ [0,1]^n 是动态权重向量
```

**问题**：如果是向量门控，融合后概率和可能不为1，不是合法概率分布

**修改为（标量门控）**：
```latex
y_GEE(x) = g_baseline(x) · y_baseline(x) + g_expert(x) · y_expert(x)

满足凸组合约束：
g_baseline(x) + g_expert(x) = 1, g_baseline(x), g_expert(x) ∈ [0,1]

门控权重通过门控网络学习得到：
g_baseline(x) = σ(v^T · h(x) + b)
g_expert(x) = 1 - g_baseline(x)
```

#### 2.2 新增概率有效性证明
**修改位置**：3.5.3节（新增）

**新增内容**：
```latex
由于 g_baseline + g_expert = 1 且 y_baseline, y_expert 都是合法概率分布，
融合后的分布仍然是归一的：

∑ y_GEE,j(x) = g_baseline ∑ y_baseline,j + g_expert ∑ y_expert,j
            = g_baseline · 1 + g_expert · 1 = 1
```

**效果**：确保数学上的自洽性，Softmax熵等度量仍然有效

### **任务4：添加形式化定义和logit几何分析** 🔸 中优先级

#### 4.1 "中性决策边界"的形式化定义
**修改位置**：3.5.2节（第394行后）

**新增定义**：
```latex
第j类原型：μ_j = (1/n_j) ∑ f(x_i)

几何偏移度：d_geo(x) = max‖f(x)-μ_j‖ / min‖f(x)-μ_j‖

- d_geo ≈ 1：边界"中性"
- d_geo ≫ 1：边界"偏移"
```

**效果**：将直觉概念转化为可度量的数学形式

#### 4.2 Logit几何分析
**修改位置**：3.5.2节（第447行后）

**新增内容**：

**(1) Logit范数分析**：
```latex
‖f(x)‖_2：高范数 → 高置信度；低范数 → 低置信度

加权CE压缩多数类扩张，使未知样本logit范数小 → 高熵
```

**(2) 类别间Margin分析**：
```latex
m(x) = min_{j≠y_true} (f_{y_true}(x) - f_j(x))

标准CE：未知样本可能获大margin（过拟合）
加权CE：未知样本margin接近0（得分相近）→ 高熵
```

**(3) 理论联系**：
```
小范数 + 小margin → logits分布均匀 → Softmax熵高 → 低置信度
```
